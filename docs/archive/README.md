# Archived Documentation / 已归档文档

> This directory contains **historical documents** from earlier phases of the
> project that have been superseded and are kept only for archaeology.
>
> 这些文档来自项目早期阶段，**已被新文档取代**，仅作历史保留。

## Why archived?

The project root previously contained 33+ `.md` files including
`PROJECT_SUMMARY.md`, `FINAL_SUMMARY.md`, `FINAL_SUMMARY_DETAILED.md`,
`RESTRUCTURE_PLAN.md`, multiple `项目*.md` files, etc.

These were generated during the project's growth phase and became
**noise for new contributors** — nobody could tell which document
was authoritative. Per a 2026-06 code review, all of them were
moved here, leaving the project root with **only the 13 documents
that are actually maintained**.
