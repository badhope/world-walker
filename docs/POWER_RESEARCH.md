# 迷雾求生类小说：什么金手指有用

样本只选“迷雾/废土/全民求生”这一支，看简介、目录和实际能力描述，不看站外榜单。

## 一、可用的四类

1. **身体强化 / 巨力**
   - 《全球迷雾求生：我能掠夺万物词条》把【巨力】和【净水】写成两种正常天赋：一个能直接在雾里杀怪，一个能持续产出饮用水。
   - 《荒原余温》开局给“无限空间仓库 + 神级身体强化”，并明确写体力 +999、抗寒 MAX。
   - 这类能力的好处是能落到数值和动作上：扛多重、打多疼、能撑多久。

2. **武器 / 锻造 / 升级**
   - 《迷雾求生：我能升级万物》写“普通木棍升级为精钢长刀”“初级体魄升级为钢铁之躯”，成长线是武器和身体一起升级。
   - 《求生：在迷雾贩卖灵魂》里武器可以随灵魂强化，主角用“裂魂铁斧”这类重武器战斗。
   - 《末日：我靠撸树，具现帝国》用石剑、火焰附魔钻石剑、TNT 桶解决战斗和守家。
   - 关键不是“神兵”，而是“手里有能砍、能砸、能守的东西”。

3. **储物 / 净化 / 生产**
   - 《废土拾荒者：我有无限空间》核心是随身空间囤物资；《神秘空间，人在废土吃香喝辣》把空间写成储物、辐射净化、接触汲取三件事。
   - 这类能力如果只有“装东西”，会变成背包；如果还能净水、保鲜、净化，就能直接解决生存痛点。

4. **建造 / 据点升级**
   - 《全球废土：避难所无限升级》《我的末日避难所能升级》把木门→铁门、木矛→电磁矛写成可见的升级链。
   - 这类金手指的爽点不是“知道危险”，而是“把屋子变厚、把武器变长、把水变干净”。

## 二、信息型为什么容易被嫌

《全球迷雾求生》柯林的“注视几秒得到提示”、《迷雾求生：我的面板只给提示》《迷雾求生：我有路径导航》《迷雾求生：我的提示全知全能》都把“知道”本身当金手指。  
这类写法在小说里可以推动剧情，但放进游戏会出现两个问题：

- 玩家得到的是“答案”，不是“手段”；知道门外有东西，仍然没有力气、没有武器、没有材料。
- 提示越全，玩家越像在看攻略，选择空间反而变小。

所以本作不再把“危险预警、物资鉴定、弱点标注、路径导航”当作爽文主能力。

## 三、本作采用的最小组合

迷雾小屋的爽文档不发明超能力，给三样能直接使用的东西：

- **旧五金工具箱**：木板、铁钉、门铰链、尼龙绳、温湿度计、打火机、羊角锤。
- **一把旧柴刀**：能砍柴、削木、防身；力量 12，柴刀劈砍 ×1.15，连砍 20 次卷刃。
- **搬货练出的身板**：力量 12（游戏基线 10），能肩扛 60kg 走 20 米；会累、会伤、会饿。

这样玩家第一晚就能做三件事：补窗、加固门、提刀去砍柴；每个动作都有材料消耗、体力消耗和暴露风险，不靠提示，也不靠读心。
