## 截图要求

### 技术要求

- **分辨率**: 1920x1080 或更高
- **格式**: PNG 或 JPG
- **质量**: 高清，无压缩伪影
- **字体**: 使用等宽字体展示代码

### 标注要求

- 使用红色或蓝色方框标注关键信息
- 添加简短文字说明
- 保持截图整洁，不添加过多装饰

### 命名规范

```
{序号}-{功能模块}.png
示例: 01-environment-check.png
```

## 演示流程

### 1. 开场介绍（1分钟）

```
"大家好，今天我想向大家展示一个区域产业经济分析平台。
这是一个面向求职的可复用分析工具，采用模块化架构设计，
以深圳半导体产业2025年为具体示例。"
```

**配合截图**: 项目结构图

### 2. 技术架构（2分钟）

```
"项目采用前后端分离的架构：
- 后端使用FastAPI提供RESTful API
- 数据处理使用Pandas和NumPy
- 可视化使用Plotly交互式图表
- 配置使用Pydantic-settings管理"
```

**配合截图**: 项目架构图、依赖技术栈

### 3. 功能演示（5分钟）

```
"现在让我演示主要功能：

第一步，环境检查..."
（运行命令，截图1）

"第二步，运行企业端分析..."
（运行命令，截图3）

"第三步，运行政府端分析..."
（运行命令，截图4）

"第四步，生成综合报告..."
（运行命令，截图5、6）

"第五步，启动API服务..."
（运行命令，截图7、8、9）
```

### 4. 核心亮点（2分钟）

```
"项目有几个核心亮点：

1. 配置化设计 - 可以轻松切换不同的地区和产业
2. 模块化架构 - 数据采集、分析、可视化独立
3. 双视角分析 - 企业端和政府端全面覆盖
4. 经济学模型 - 集成菲利普斯曲线、柯布-道格拉斯等"
```

### 5. 求职优势（1分钟）

```
"这个项目在求职中很有优势：

1. 真实场景 - 以深圳半导体产业为案例，数据真实
2. 技术栈完整 - FastAPI、Pandas、Plotly都是主流技术
3. 架构设计 - 模块化、配置化体现工程能力
4. 文档完整 - README、配置指南、开发文档齐全
5. 可扩展性 - 方便添加新的地区和产业配置"
```

### 6. 结尾（1分钟）

```
"以上就是我的项目展示。

项目地址：https://github.com/badhope/national_stats

感谢大家的聆听！"
```

## 演示环境准备

### 硬件要求

- 内存: 8GB+
- 硬盘: 10GB+
- 网络: 稳定（用于演示在线功能）

### 软件要求

- Python 3.9+
- Git
- 代码编辑器（VS Code推荐）
- 浏览器（Chrome推荐）

### 演示前检查清单

- [ ] 所有依赖已安装
- [ ] 示例数据已准备
- [ ] API服务可正常启动
- [ ] 截图文件已保存
- [ ] 代码已提交到Git
- [ ] README已更新

### 备选方案

1. **网络不稳定**: 提前下载所有依赖，准备离线演示
2. **API无法启动**: 准备录制的API调用视频作为备选
3. **代码报错**: 准备详细的错误处理说明，展示调试能力

## 常见问题

### Q: 演示时间不够怎么办？

**A**: 精简到3个核心功能：
1. 环境检查 + 一键安装
2. 企业端分析 + 政府端分析
3. API服务 + 接口演示

### Q: 遇到技术问题怎么办？

**A**: 
- 展示排查问题的过程，体现能力
- 说明可能的原因和解决方案
- 后续会持续优化

### Q: 如何吸引面试官注意？

**A**:
1. 强调项目解决了什么问题
2. 展示数据分析和可视化的能力
3. 体现配置化和模块化的工程思维
4. 说明项目的可扩展性和复用性
