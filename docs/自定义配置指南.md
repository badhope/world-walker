## 快速开始（3步创建新配置）

### 第1步：创建配置文件

在 `/workspace/configs/` 目录下创建 `your_industry.yaml` 文件：

```yaml
# 项目基本信息
project_name: your_project_name
regions: ["地区1", "地区2", "地区3"]

# 行业配置
industry:
  industry_id: your_industry_id
  industry_name: 你的行业名称
  industry_type: manufacturing  # 可选: manufacturing, services, tech, retail
  description: 行业描述
  
  # 定义评分维度
  dimensions:
    - name: dimension_1
      display_name: 维度1显示名
      description: 维度描述
      weight: 0.40  # 权重，所有维度权重之和应为1.0
      metrics: ["metric_1", "metric_2", "metric_3"]
      metric_weights:
        metric_1: 0.50
        metric_2: 0.30
        metric_3: 0.20
      higher_is_better:
        metric_1: true
        metric_2: false
        metric_3: true
    
    - name: dimension_2
      display_name: 维度2显示名
      description: 维度描述
      weight: 0.35
      metrics: ["metric_4", "metric_5"]
      metric_weights:
        metric_4: 0.60
        metric_5: 0.40
      higher_is_better:
        metric_4: true
        metric_5: false

  # 定义指标
  metrics:
    metric_1:
      name: metric_1
      display_name: 指标1显示名
      unit: "单位"
      description: 指标描述
      data_source: 数据来源
      benchmark_method: percentile  # percentile, fixed, dynamic
    
    metric_2:
      name: metric_2
      display_name: 指标2显示名
      unit: "单位"
      description: 指标描述
      data_source: 数据来源
      benchmark_method: percentile

  # 成功指标（用于评估的关键指标）
  success_metrics: ["metric_1", "metric_4"]
  
  # 数据需求（必需的数据字段）
  data_requirements: ["metric_1", "metric_2", "metric_3", "metric_4", "metric_5"]

# 机器学习配置
ml:
  models: 
    - xgboost
    - random_forest
    - gbdt
    - prophet
    - linear_regression
  target_metric: metric_1  # 预测目标
  feature_columns:  # 特征列
    - metric_2
    - metric_3
    - metric_4
  time_column: year
  id_column: region_id
  train_size: 0.8
  hyperparameter_tuning: true
  cross_validation_folds: 5

# 数据配置
data: {}
```

### 第2步：准备数据

创建CSV数据文件 `your_data.csv`：

```csv
region_id,region_name,year,source,metric_1,metric_2,metric_3,metric_4,metric_5
region_001,地区1,2020,sample,100,50,80,30,60
region_001,地区1,2021,sample,110,55,85,32,62
region_002,地区2,2020,sample,95,48,78,28,58
region_002,地区2,2021,sample,105,53,83,31,60
```

### 第3步：运行分析

```python
from backend import UniversalAnalyzer

# 创建分析器
analyzer = UniversalAnalyzer(config_name='your_industry')

# 加载数据
dataset = analyzer.load_data_from_dataframe(pd.read_csv('your_data.csv'), name='your_data')

# 运行分析
result = analyzer.analyze(
    run_ml=True,
    target_column='metric_1',
    feature_columns=['metric_2', 'metric_3', 'metric_4']
)

print(f"最佳模型: {result.ml_result.best_model.model_name}")
print(f"R²分数: {result.ml_result.best_model.metrics.r2:.4f}")
```

## 行业配置模板

以下是各行业的配置模板参考：

### 1. 零售行业
- 维度：选址、客群、运营、成本
- 指标：客流量、租金、人力成本、库存周转率

### 2. 制造业
- 维度：质量、效率、成本、创新
- 指标：合格率、生产周期、材料成本、研发投入

### 3. 医疗健康
- 维度：需求、竞争、资源、质量
- 指标：人口、老龄化、医护比、床位使用率

### 4. 金融行业
- 维度：规模、风险、盈利、创新
- 指标：资产、不良率、ROE、金融科技投入

### 5. 教育行业
- 维度：规模、质量、成本、满意度
- 指标：学生数、升学率、生均成本、满意度评分

### 6. 物流行业
- 维度：网络、效率、成本、服务
- 指标：覆盖率、配送时效、单均成本、客户好评率

## 最佳实践

### 1. 维度权重设计
- 所有维度权重之和应等于1.0
- 根据业务重点分配权重
- 维度数量建议3-5个

### 2. 指标选择
- 选择可量化、有数据支持的指标
- 避免过多指标（建议每个维度3-5个）
- 明确 `higher_is_better` 标识

### 3. 数据准备
- 确保数据完整性
- 统一数据单位和时间范围
- 清理异常值

### 4. 机器学习配置
- 选择合适的预测目标
- 特征列应与业务相关
- 使用交叉验证确保模型稳健

## 常见问题

**Q: 如何添加新指标？**
A: 在 `metrics` 部分添加新指标定义，并在 `data_requirements` 中列出。

**Q: 如何调整维度权重？**
A: 修改 `dimensions` 中每个维度的 `weight` 值，确保总和为1.0。

**Q: 如何选择机器学习模型？**
A: 系统会自动对比所有模型并选择最优，无需手动选择。

**Q: 如何处理缺失数据？**
A: 系统会自动处理缺失值，也可在 `clean_data` 方法中自定义处理逻辑。
