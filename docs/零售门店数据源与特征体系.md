## 二、特征工程体系

### 2.1 基础特征

| 特征名称 | 特征说明 | 计算方式 | 预期影响方向 |
|----------|----------|----------|--------------|
| store_area | 门店面积 | 直接使用 | +（面积大销量高，但边际递减） |
| is_weekday_open | 是否工作日营业 | 0/1 | + |
| is_holiday_open | 是否节假日营业 | 0/1 | + |
| open_days | 营业天数/周 | 直接使用 | + |

---

### 2.2 位置与交通特征

| 特征名称 | 特征说明 | 计算方式 | 预期影响方向 |
|----------|----------|----------|--------------|
| distance_to_subway | 到地铁口距离 | 直接使用（取对数更好） | -（越近越好） |
| bus_stop_count_500m | 500米内公交站数 | 直接使用 | + |
| parking_lot_count | 周边停车位 | 直接使用 | + |
| distance_to_main_road | 到主干道距离 | 直接使用 | - |
| is_main_street | 是否主街位置 | 0/1 | + |
| business_district_type | 商圈类型 | one-hot编码 | 视类型而定 |
| visibility_score | 可视性评分 | 1-10分 | + |

---

### 2.3 人口特征

| 特征名称 | 特征说明 | 计算方式 | 预期影响方向 |
|----------|----------|----------|--------------|
| population_1km | 1公里覆盖人口 | 直接使用（取对数） | + |
| population_2km | 2公里覆盖人口 | 直接使用（取对数） | + |
| population_density | 人口密度 | 直接使用 | + |
| avg_age | 平均年龄 | 直接使用 | 视业态而定 |
| young_ratio_18_30 | 年轻人占比 | 直接使用 | 视业态而定 |
| avg_income | 人均可支配收入 | 直接使用（取对数） | + |
| household_count | 家庭户数 | 直接使用 | + |

---

### 2.4 竞争特征

| 特征名称 | 特征说明 | 计算方式 | 预期影响方向 |
|----------|----------|----------|--------------|
| competitor_count_1km | 1公里竞品数 | 直接使用 | -（竞争激烈） |
| competitor_count_2km | 2公里竞品数 | 直接使用 | - |
| distance_to_nearest_competitor | 最近竞品距离 | 直接使用 | +（越远竞争越小） |
| avg_competitor_area | 竞品平均面积 | 直接使用 | - |
| top_brand_count | 头部品牌数 | 直接使用 | - |
| market_saturation | 市场饱和度 | 竞品数/人口数 | - |

---

### 2.5 租金与成本特征

| 特征名称 | 特征说明 | 计算方式 | 预期影响方向 |
|----------|----------|----------|--------------|
| rent_per_sqm | 单位面积租金 | 直接使用 | 与区域价值正相关 |
| rent_to_area_ratio | 租金面积比 | 租金/面积 | 反映位置优劣 |
| regional_avg_rent | 区域平均租金 | 直接使用 | +（区域越好租金越高） |
| labor_cost | 人力成本 | 直接使用 | 控制变量 |

---

### 2.6 组合特征与衍生特征

| 特征名称 | 特征说明 | 计算方式 |
|----------|----------|----------|
| population_per_competitor | 人均竞品数 | 人口_1km / 竞品数_1km |
| rent_to_population | 租金人口比 | 租金 / 人口_1km |
| accessibility_score | 可达性综合分 | 地铁权重×0.4 + 公交权重×0.3 + 停车权重×0.3 |
| competition_intensity | 竞争强度 | 竞品数_1km × (1 / 距离最近竞品) |
| potential_score | 潜力综合分 | 可达性×0.3 + 人口×0.4 + 竞争×0.3 |

---

### 2.7 时间与季节特征

| 特征名称 | 特征说明 | 计算方式 |
|----------|----------|----------|
| month | 月份 | 1-12 |
| quarter | 季度 | 1-4 |
| is_holiday_season | 是否节假日季节 | 0/1 |
| open_months | 已开业月数 | 直接使用 |

## 三、数据获取渠道详细说明

### 3.1 公开免费数据源

1. **政府统计部门**
   - 国家/地方统计局官网
   - 人口普查数据
   - 经济普查数据
   - 区域统计年鉴

2. **地图开放平台**
   - 高德地图开放平台
   - 百度地图开放平台
   - 腾讯地图开放平台
   - 提供：POI数据、交通数据、商圈数据

3. **开源数据集**
   - Kaggle相关数据集
   - 天池竞赛数据
   - 各类开放数据平台

### 3.2 商业数据来源

1. **第三方数据服务商**
   - 移动运营商位置数据
   - 支付平台消费数据
   - 导航地图客流数据

2. **行业协会**
   - 连锁经营协会
   - 零售行业协会

3. **市场调研公司**
   - 专业零售调研数据

### 3.3 企业内部数据

1. **POS系统**：销售数据、客流数据
2. **ERP系统**：门店信息、成本数据
3. **CRM系统**：会员数据、消费行为
4. **历史项目**：过往选址评估资料
