# 用 World Games 做什么

> 这份文档不讲架构，只回答一个问题：**你拿它能干什么，第一步做什么。**
> 如果你只读一份文档，读这份。

---

## 三十秒理解

**普通 AI 角色扮演**：你说一句话，模型编一段剧情，顺手编掉你的血量和钱。玩到第三十回合，
它忘了你欠谁钱、忘了你左手还有伤，物价今天 3 块明天 300。

**World Games**：模型只负责写文字。血量、价格、关系、势力、因果债全由规则函数算，
写进一个 JSON。所以第三十回合和第三百回合，账还是对的；同一个种子重放，结果一模一样。

一句话：**它是给 AI 用的"游戏规则引擎"，不是又一个 AI 聊天前端。**

## 五种人，五种用法

### 1. 想认真玩一局长期游戏的人

传统 AI 文字游戏撑不过几十回合：模型记不住，数值会漂。这里能撑几百回合。

```
wg init my-game.json
wg play --state my-game.json
```

浏览器打开主舞台，你在对话框里跑 Agent，面板只读地跟着变。
左边是你的角色和资源，中间是叙事与判定记录，右边是在场的人和关系。

**适合**：喜欢长线养成、在意"我到底有多少钱、欠谁的债"的玩家。

### 2. 想做一个自己的文字游戏的人

不想写代码，只想定义世界观。

1. 复制 `settings/玄枢界.setting.json`（或任一设定包）
2. 改 `world` / `player` / `entities` / `market` / `places` / `lore`
3. 改 `terms`：把你的世界词汇填进去（`level: "境界"` → `level: "职级"`）
4. 跑 `python scripts/verify_settings.py` 验证

**不需要改引擎任何一行代码。** 换世界只换 JSON。

**适合**：有世界观设定但不会编程的作者、跑团主持人、同人创作者。

### 3. 想让 AI 助手"有记忆、不瞎编"的开发者

你的 Agent 现在可以调用 64 个工具做真实结算：

```
用户：我去码头打听灯塔的事

Agent 内部：
  context_pack(scene_text="码头 灯塔")        # 这一回合该给模型什么材料
  roll(attribute="per", difficulty=9, dice="2d6")   # 真掷骰
  context_remember("门房说昨夜灯塔亮过")       # 记住这条线索
  publish_prose("雨没停。门房把烟摁在窗台上……")  # 写正文
  tick()                                      # 世界往前走一回合
```

**适合**：做 AI 游戏、AI 陪伴、AI 跑团的工程师。

### 4. 想研究"AI + 规则"怎么做的人

项目是一个可拆开看的样本：

- 每种玩法机制怎么拆成数据（7 类可插拔体系）
- 叙事怎么和数值解耦（判定记录与正文分离）
- 长局记忆怎么不爆（三层记忆 + 有界台账）
- 怎么证明它确实可复现（动作日志 + 变异测试）

`docs/PRIOR_ART.md` 里有 12 个对标项目的机制拆解和取舍理由。

**适合**：做研究、写文章、需要参考实现的人。

### 5. 想验证"AI 能不能主持游戏"的人

引擎不调用任何模型。它假设**模型由外面提供**，自己只做结算。

所以你换 GPT、Claude、本地模型，游戏规则不变。
测的正是"模型作为主持人"这件事本身。

## 第一次玩，走这条路径

### 路径 A：五分钟看效果（不装 Python）

1. 下载 `world-games.exe`
2. `world-games.exe init demo.json`
3. `world-games.exe play --state demo.json`
4. 浏览器自动打开，看到一局真实存档
5. 想看真实对局长什么样：直接把 `docs/demo/玄枢界.save.json` 拷过去打开

### 路径 B：接上你的 Agent（推荐）

```bash
pip install -e ".[mcp]"
```

MCP 客户端配置：

```json
{ "mcpServers": { "world-games": { "command": "world-games-mcp" } } }
```

然后在对话里说：

```
帮我开一局玄枢界的游戏
```

Agent 会依次调 `load_setting` → 写开场 → 等你行动。
**之后你正常说话就行**，它会在需要数字时自己调工具。

### 路径 C：做自己的世界

1. 读 [`GAMEPLAY.md`](GAMEPLAY.md) 了解 playbook / questline / lorebook
2. 复制一个设定包，改字段
3. `python scripts/verify_settings.py` 检查
4. `load_setting` 载入

## 它解决的具体问题

| 你会遇到的麻烦 | 这里怎么解决 |
|---|---|
| 模型编造伤害和价格 | `combat` / `trade` 由规则函数算，同种子可复现 |
| 玩久了模型忘记前面的事 | 上下文台账落盘，`context_pack` 按预算取回；检索按 Generative Agents 的三分量打分 |
| 存档越玩越乱 | 存档库：多局、快照、回收站，统一 `session_*` |
| 不行动世界就静止 | `tick` 推进势力、谣言、风气、NPC、Panarchy 相位 |
| 换个世界要重写代码 | 设定包是一个 JSON，术语/等级/货币/地点全在里面 |
| 不知道数值对不对 | 每条事件有结构化字段，动作日志可重放 |
| 玩家卡在原地打转 | 循环检测：同一状态出现三次就提示换场景 |

## 不该用它做什么

- **不是聊天前端**。它没有对话界面，界面是只读面板。对话在你的 Agent 里。
- **不生成图片**。它是规则层，视觉留给宿主。
- **不做多人联机**。单机本地工具，一个存档一个写入者。
- **不替代 GM**。它算数，不讲故事——故事由模型讲。

这些是取舍不是遗漏，理由在 [`ROADMAP.md`](../ROADMAP.md)。

## 四个开箱即玩的世界

| 设定包 | 题材 | 玩法循环 | 一局大概什么感觉 |
|---|---|---|---|
| 玄枢界 | 东方玄幻 | 自由推进 | 修行、争资源、宗门倾轧，十阶登顶 |
| 折剑行 | 武侠 | 声明→判定→后果 | 接活、踩点、动手、还债，七阶身手 |
| 霓虹深渊 | 赛博朋克 | 地点命令 | 跑腿、接头、侵入、翻车，F–S 评级 |

八个模板覆盖更多题材（`jrpg` / `mystery` / `management` / `survival` / `narrative` / `cozy` /
`tabletop` / `immersive`），`template_start(template="mystery")` 直接开局。

## 常见疑问

**我不会编程，能用吗？**
能用 exe 玩现成的四套世界。做自己的世界需要改 JSON——比编程简单，但需要细心。

**一定要装 Python 吗？**
不。exe 版不需要。只有想改代码或跑测试才需要。

**它会调用大模型吗？**
不会，一个 API 都不调。模型由你的 Agent 提供。

**存档在哪？**
默认当前目录。`wg doctor` 会打印所有路径。

**玩坏了吗？**
`session_snapshot` 随时拍快照，`restore` 回退。快照只切换归档文件，不删历史。
