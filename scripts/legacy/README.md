# Legacy

These were one-off scripts that ended up in the project root during
build-out (`demo_*.py`, `test_*.py`, `verify_*.py`, `diagnose_*.py`).
They duplicated things now covered by `pytest tests/backend/` or
`python full_diagnose.py`, so they were moved here to keep the root
clean.

If you came here looking for the entry point, it's `main.py` at the
project root.
