    这是什么

    一局由规则引擎结算的文字互动游戏，这块面板是它的只读实况主舞台—— 显示的是状态文件里真实的结果。你（玩家）和对局助手在别处行动，面板只跟着变， 不会改对局，也不会替你掷骰子。

    术语表 引擎概念的人话版

    气血 / 内力
    生命与可消耗的爆发资源。气血低于三成会亮起"气血吃紧"。
    钱财
    本世界的货币（玄晶/灵石/信用点…由设定决定）。买入会增加，卖出会回归。
    心流（flow）
    战斗难度的舒适度：赢得太容易会"无聊"，输太多会"焦虑"，正好在挑战区才叫心流。
    世界相位（Panarchy）
    世界所处的阶段：增长 / 保护 / 崩溃释放 / 重组。大事件的烈度跟着它走。
    未清因果债
    你做过的"业"（杀人、偷窃…）累积的债。债越重，突破成功率被压得越低。
    修行阶段（stage）
    本次突破的次数进度。到上限后不再增长——该换更强的对手或更远的世界了。
    物价指数
    全市场"当前价 ÷ 基准价"的均值。1.0 是正常，越低越适合囤货。
    心意（亲密 / 敬重）
    人物关系两维：喜欢你和怕你/服你，是两码事。
    探索图鉴
    去过的地方、见过的人、经手的物、触发过的设定——你自己不用记。
    势力与风向
    各方存量会随回合自行消长；传闻热度越高，越可能引来是非。你不用管它，它也会动。
    这一回合的正文
    中间那段字是你这一步的叙事正文；它由宿主写进存档，换设备打开也是同一段。

    图表怎么读

    • 行藏曲线：气血/内力按百分比看左轴，钱财看右轴（虚线）。陡降常是打架与突破的代价。
    • 业债与心境：柱是未清业债，线是人情均值。杀人偷窃柱会跳，帮人还债会回落。
    • 市价偏离：贴着基准线 1.0 走动；明显低于基准＝本地有折价货。
    • 事件谱：最近事件按危急/警示/顺遂/寻常分档，看得出这段是太平还是多事。

    键盘 keyboard

    • ? 打开/关闭本帮助；Esc 关闭任何弹窗（焦点会回到你原来待的控件）。
    • Ctrl/⌘ + K 命令面板（图鉴 / 市场 / 导出 / 分享模式…），↑↓ 选择、Enter 执行。
    • Tab 在控件间移动；抽屉与按钮都可用 Enter/Space 展开。
    • 顶栏「动效：开/关」可暂停所有过渡动画（系统级"减少动态效果"也会自动生效）。

    数据与隐私

    • 状态文件：—（对局的唯一权威，一切数值以它为准）
    • 趋势侧写：—（面板自己的采样账本，删了只丢曲线，不伤对局）
    • 行动队列：你在下方输入的行动会写进同目录的收件箱，由对局助手取走结算——面板本身从不改对局状态。
    • 面板只监听本机 127.0.0.1，不向任何外部服务发送数据。
