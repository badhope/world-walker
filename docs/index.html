你开口，世界回应。

单人 AI 跑团 / 互动叙事引擎。你直接和 AI 对话，规则引擎负责判定、状态和存档；也可以把自己的 AI 通过 MCP 接进来当 GM。

打开就能玩

本地页面 + 任意 OpenAI-compatible 模型。三张旗舰开局卡可以直接进；也可以先问类型、玩法、角色与体验，再给开局卡。不预写剧情。

规则引擎说了算

命中、伤害、价格、关系、因果都由确定性规则结算。模型负责叙述，不负责编数值。

把你的 AI 接进来

MCP 独立模式没有本地页面。外部 AI 自己当 GM，通过对话展示地点、人物与场面。

快速开始

pip install -e ".[mcp]"
wg mcp                 # stdio
wg mcp --http --port 8620

模型不绑定厂商；base_url / api_key / model 都可以在配置里替换。

看得见的状态变化

每段叙述下面都有本回合的气血、物品、压力钟与关系差异；菜单里能回看战报、导出 Markdown、把世界包交给另一台机器，或导出/导入角色卡。

两条入口，一套引擎

玩家页面和 MCP 模式共用同一套规则、存档与事务写入。MCP 模式不调用 open_panel，这是故意的：它应该看起来像一场纯对话，而不是仪表盘。
