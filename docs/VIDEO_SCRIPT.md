# 🎬 视频录制脚本

本文档提供录制项目演示视频的完整脚本和指导。

## 视频信息

- **视频时长**: 5-8分钟
- **视频格式**: MP4 (H.264)
- **分辨率**: 1920x1080
- **帧率**: 30fps
- **音频**: MP3, 128kbps

## 录制前准备

### 1. 环境准备

```bash
# 1. 清理不必要的文件
find . -type f -name "*.pyc" -delete
find . -type d -name "__pycache__" -exec rm -rf {} +

# 2. 重置到干净状态
git status

# 3. 准备演示数据
ls examples/shenzhen_semiconductor_2025/data/
```

### 2. 工具准备

- **录屏软件**: OBS Studio (免费) / Camtasia / Loom
- **麦克风**: 外接麦克风效果更好
- **编辑器**: VS Code (推荐主题: One Dark Pro)

### 3. 录制设置

```markdown
OBS Studio 设置:
- 输出分辨率: 1920x1080
- 编码器: x264 (或硬件编码器)
- 码率: 5000-8000 kbps
- 帧率: 30fps
- 音频: 128kbps, 44100Hz

推荐快捷键:
- F9: 开始/停止录制
- F10: 暂停/恢复
- Ctrl+Shift+R: 录制特定区域
```

## 录制技巧

### 1. 语速控制

- **正常语速**: 150-180字/分钟
- **关键内容**: 适当放慢，给观众思考时间
- **代码展示**: 稍快，重点在结果

### 2. 画面切换

- **每次切换**: 留1-2秒缓冲
- **代码和说明**: 先展示代码，再口述解释
- **数据标注**: 使用箭头或方框突出关键信息

### 3. 声音处理

- **环境噪音**: 安静的房间，使用外接麦克风
- **背景音乐**: 片头片尾使用，录制时关闭
- **音量平衡**: 旁白和背景音乐音量协调

### 4. 错误处理

- **录制出错**: 使用Ctrl+Z撤销，或重新录制该段落
- **口误**: 简短重复正确内容，继续录制
- **技术问题**: 暂停录制，处理完后继续

## 常见问题

### Q: 视频太大怎么办？

**A**: 
- 降低码率到3000-5000 kbps
- 删除不必要的片段
- 使用压缩工具（HandBrake免费）

### Q: 声音不清晰怎么办？

**A**:
- 使用降噪滤镜
- 提高音量
- 重新录制关键段落

### Q: 代码显示不完整怎么办？

**A**:
- 调整终端字体大小（推荐14-16pt）
- 使用等宽字体（Consolas, Monaco）
- 全屏录制代码窗口
