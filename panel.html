让外部 Agent 接管对话，走这一页。模型和 Key 由 Agent 自己配置；面板只提供 MCP 端点。

1. 启动 MCP 服务

在仓库目录执行。HTTP 模式适合远程 Agent；stdio 模式适合本机客户端。

python3 cli.py mcp --http --port 8620

安装之后也可以直接用 wg mcp --http --port 8620。

2. 在 Agent 里填端点 
http://127.0.0.1:8620/mcp
本机 stdio 客户端配置 
{
  "mcpServers": {
    "world-walker": {
      "command": "world-walker-mcp"
    }
  }
}

远端 Agent 连上后，用 session_zero 或 template_start 开局；不要在面板里重复填 Key。
