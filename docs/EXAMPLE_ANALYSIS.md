### 3. 风险 + 4 档情景

```bash
curl -s 'http://localhost:8000/api/v1/investment/risk/city/shenzhen?indicator=gdp' | jq '.garch'
curl -s 'http://localhost:8000/api/v1/investment/scenarios/city/shenzhen?indicator=gdp&years=5' | jq '.scenarios'
```

输出:
- GARCH(1,1) 条件波动率 + 持续性 + 半衰期
- 4 档情景(baseline / +10% / -10% / -25%)的累积值

### 4. Monte Carlo 尾部概率

```bash
curl -s 'http://localhost:8000/api/v1/investment/monte-carlo/city/shenzhen?indicator=gdp&years=5' | jq '.percentiles'
```

返回 P5/P50/P95 三年/五年尾部概率(1000-iter 残差 bootstrap)。

### 5. 投资决策使用建议

详见 [docs/METHODOLOGY.md §8](METHODOLOGY.md) — 8 项决策准则:
1. ensemble.verdict == "PASS" → 预测可信
2. coverage > 0.9 → CI 可靠
3. GARCH persistence < 0.9 → 波动率不聚集,VaR 估计稳
4. 4 档情景 spread < 20% → 行业稳定,投资信心足
5. P5 > baseline × 0.8 → 极端下行风险可控

满足 ≥4 项可作为决策依据,否则人工 review。

## 案例背景

### 1.1 产业定位

深圳是中国最重要的半导体产业集聚地之一，形成了从设计、制造到封测、应用的全产业链布局。

**产业规模：**
- 总产值：12,000亿元
- 占全国比例：28.5%
- 企业数量：2,000家
- 从业人员：28.5万人

### 1.2 分析范围

本案例从**企业端**和**政府端**两个视角进行综合分析：

- **企业端**：帮助企业了解营商成本、供应链、政策红利
- **政府端**：帮助政府评估政策效果、产业带动效应

### 1.3 数据来源

- 深圳市统计局
- 深圳市半导体行业协会
- 国家统计局
- 企业年报

## 核心发现

### 3.1 综合营商成本

**核心指标：**

| 指标 | 数值 | 全国排名 |
|------|------|----------|
| 综合成本指数 | 100 | 第4位 |
| 土地成本 | 812元/㎡·年 | 偏高 |
| 人力成本 | 18,500元/月 | 偏高 |
| 能源成本 | 0.68元/kWh | 适中 |
| 融资成本 | 3.85%（中企） | 适中 |

**分析结论：**
深圳综合营商成本位居全国第四，但凭借完善的产业链和人才集聚优势，仍具有较强竞争力。

### 3.2 产业链覆盖度

**各环节覆盖度：**

| 环节 | 覆盖度 | 描述 |
|------|--------|------|
| 上游（设计/材料/设备） | 65% | 设计强，材料和设备依赖进口 |
| 中游（制造/封测） | 85% | 制造能力强，封装测试完善 |
| 下游（应用/终端） | 95% | 应用场景丰富，市场活跃 |

**关键瓶颈：**

1. **高端光刻机（EUV）** - 进口依赖100%
2. **高端光刻胶** - 进口依赖95%
3. **12英寸硅片** - 进口依赖90%

**财政投入：**

| 指标 | 数值 |
|------|------|
| 总投资 | 158.5亿元 |
| 撬动社会资本 | 425亿元 |
| 杠杆倍数 | 1.68倍 |
| 投入产出比 | 2.35倍 |

**乘数效应：**

**解读：** 深圳半导体产业集聚度是全国平均水平的2.85倍，表明产业高度集聚，具有明显的规模经济效应。

## 分析方法论

### 6.1 区位熵计算

区位熵是衡量产业集聚程度的重要指标：

```
LQ = (Qi / Q) / (Ni / N)

其中：
- Qi: 深圳半导体产业产值
- Q: 深圳工业总产值
- Ni: 全国半导体产业产值
- N: 全国工业总产值
```

**结果解读：**
- LQ > 1：产业集聚度高于全国平均
- LQ = 1：产业集聚度等于全国平均
- LQ < 1：产业集聚度低于全国平均

### 6.2 财政乘数计算

财政支出乘数衡量财政投入对经济的拉动作用：

```
K = ΔY / ΔG

其中：
- ΔY: GDP增量
- ΔG: 财政支出增量
```

**深圳半导体产业财政乘数：2.85**

意味着每投入1元财政资金，可带动2.85元GDP增长。

### 6.3 投入产出分析

基于柯布-道格拉斯生产函数：

```
Y = A × K^α × L^β

其中：
- Y: 产业产值
- A: 技术进步因子
- K: 资本投入
- L: 劳动投入
- α: 资本弹性系数
- β: 劳动弹性系数
```
